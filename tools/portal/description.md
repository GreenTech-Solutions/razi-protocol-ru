# Razi Protocol: русская локализация модов

Русская локализация модов сборки [Razi Protocol](https://mods.factorio.com/mod/razi-protocol), которые не переведены или переведены не полностью. Razi Protocol подключает этот мод как необязательную зависимость: установите его, если играете на русском.

## Откуда перевод

Мод добавляет только те строки, которых нет в переводе самого мода или Razi Protocol: если у мода есть свой перевод, используется он. Большая часть строк взята из паков переводов с портала, остальные переведены вручную.

| Пак переводов | Автор | Лицензия |
| --- | --- | --- |
| [russianlocalizationpalnet](https://mods.factorio.com/mod/russianlocalizationpalnet) | weydarkend | MIT |
| [ru-planets-and-more](https://mods.factorio.com/mod/ru-planets-and-more) | Derneder | MIT |
| [rus-perevod](https://mods.factorio.com/mod/rus-perevod) | Severeniys | MIT |
| [RULocale_fromSLL](https://mods.factorio.com/mod/RULocale_fromSLL) | S-L-L | The Unlicense |
| [locale_ru](https://mods.factorio.com/mod/locale_ru) | KeySiVi | MIT |

## Нашли ошибку?

Об ошибках и непереведённых строках пишите в [issues на GitHub](https://github.com/GreenTech-Solutions/razi-protocol-ru/issues) или в обсуждениях на этой странице.

**English.** Russian translation for the mods of the Razi Protocol modpack that ship no Russian locale or only part of it. A string is included only when neither the mod itself nor Razi Protocol has its own Russian for it. The strings come from the translation packs listed above and from hand-written translations; their licenses are in the LICENSE file.
